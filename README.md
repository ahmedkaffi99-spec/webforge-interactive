# WebForge Interactive

An immersive, futuristic website concept exploring motion, depth and interaction.

## Features
- Responsive landing page
- Animated orbital visual (CSS)
- Interactive 3-card carousel
- GSAP entrance animations
- Mobile navigation
- Smooth section navigation

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Built with React, Vite, GSAP and Lucide.
